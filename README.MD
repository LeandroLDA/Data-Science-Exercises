<a name="english"></a>
## 🇺🇸 English Version

### 🎯 Objective
To practice and master the fundamental tools of a Data Scientist. These isolated exercises focus on building "muscle memory" for syntax, logical problem-solving, and the practical application of specific libraries in simulated real-world scenarios.

### 📚 Topics & Courses Covered So Far
- **Python Programming & Best Practices:** Basic syntax, control flow, loops, dictionaries, Python Toolbox, modular coding, writing and documenting robust user-defined functions, error handling (`try/except`), and list/dict comprehensions.
- **Data Ingestion, Cleaning & Manipulation (Pandas):** Importing flat and structured files, handling messy data, categorical data encoding/ordering, date and time manipulation (`datetime`), subsetting, aggregating (`groupby`), and advanced data merging (`merge`, `concat`, `merge_asof`, `merge_ordered`).
- **Exploratory Data Analysis (EDA) & Communication:** Data validation, missing value imputation, outlier detection (IQR), feature engineering (`pd.cut`, `crosstab`), and core concepts of data communication and storytelling.
- **Data Visualization:** Narrative structure, figure customization, and statistical graphing using **Matplotlib** and **Seaborn** (relational, categorical, distribution plots, and heatmaps).
- **Statistical Inference & Experimental Design:** Summary statistics, sampling techniques (simple, stratified, cluster, bootstrap), hypothesis testing (t-tests, ANOVA, Chi-square, proportion tests), and experimental design fundamentals.
- **Statistical Modeling & Machine Learning:** Linear and logistic regression with **statsmodels**, along with Supervised Learning with **Scikit-Learn** (classification, regression, model evaluation metrics, cross-validation, and hyperparameter tuning).

<a name="português"></a>
## 🇧🇷 Versão em Português

### 🎯 Objetivo
Praticar e dominar as ferramentas fundamentais de um Cientista de Dados. Estes exercícios isolados focam em construir "memória muscular" para sintaxe, resolução lógica de problemas e a aplicação prática de bibliotecas específicas em cenários reais simulados.

### 📚 Tópicos e Cursos Cobertos Até o Momento
- **Programação em Python e Boas Práticas:** Sintaxe básica, estruturas de controle, loops, dicionários, Caixa de Ferramentas Python, modularização, criação/escrita de funções robustas, tratamento de erros (`try/except`) e list/dict comprehensions.
- **Importação, Limpeza e Manipulação de Dados (Pandas):** Importação de arquivos, limpeza e padronização de dados, trabalho com dados categóricos, manipulação de datas e horários (`datetime`), filtragem, agregação (`groupby`) e cruzamento avançado de tabelas (`merge`, `concat`, `merge_asof`, `merge_ordered`).
- **Análise Exploratória de Dados (EDA) e Comunicação:** Validação de dados, imputação de nulos, detecção de outliers (IQR), engenharia de variáveis (`pd.cut`, `crosstab`) e conceitos fundamentais de comunicação de dados e storytelling.
- **Visualização de Dados:** Estruturação visual, subplots e customização gráfica usando **Matplotlib** e **Seaborn** (gráficos relacionais, categóricos, distribuições e mapas de calor).
- **Inferência Estatística e Planejamento Experimental:** Estatística descritiva, técnicas de amostragem (simples, estratificada, bootstrap), testes de hipóteses (testes t, ANOVA, qui-quadrado, testes de proporção) e fundamentos de projetos experimentais.
- **Modelagem Estatística e Machine Learning:** Regressão linear e logística com **statsmodels**, além de Aprendizado Supervisionado com **Scikit-Learn** (classificação, regressão, métricas de avaliação, validação cruzada e ajuste de hiperparâmetros).
